This is an assignment for CAB302. It uses JAVAFX and is designed to be a geography style learning game. 

TO RUN (NOT TESTED IF THIS IS EXACTLY WHAT IS NEEDED JUST TYPING FOR NOW):
git clone https://github.com/CAB302-Intelli5/Geofarer
git cd Geofarer
git lfs install
git lfs pull

Now the project should be in a working state. 

Now use mvn JAVAFX:RUN in the console. If using intelliJ use the maven terminal to the right and run this command. 
The github large file system pulls down the raster image which we have not compressed in size. 

This project uses natural earth https://www.naturalearthdata.com/, and geo tools https://geotools.org/
